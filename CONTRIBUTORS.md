## How to contribute

1. Read [AGENTS.md](AGENTS.md), [ARCHITECTURE.md](ARCHITECTURE.md) and [STYLEGUIDE.md](STYLEGUIDE.md).
2. Fork the repo and create a branch from `main` (`feat/...`, `fix/...`, `chore/...`).
3. Make your change, add tests, and run `make check` locally.
4. Open a pull request using one of the templates under `.github/PULL_REQUEST_TEMPLATE/`.

This list is intentionally lightweight; meaningful contributions get added via PR.
